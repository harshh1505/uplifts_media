# Backend Logic & Configuration

This directory contains the database schema and configurations for your Supabase backend.

## Contents
- `schema.sql`: The SQL script used to initialize the `leads` table and Row Level Security (RLS) policies in Supabase.

## Setup
1. Copy the contents of `schema.sql`.
2. Paste into the **SQL Editor** of your Supabase dashboard.
3. Run the script.
